## Stellar Burgers — Unit Tests

### Описание проекта

Проект содержит юнит-тесты для класса Burger — модели бургера из приложения Stellar Burgers.

Тесты проверяют корректность работы методов класса, используя библиотеку pytest, моки из unittest.mock и параметризацию тестовых данных.

### Технологии

Python

pytest

pytest-cov

unittest.mock

### Установка и запуск

1. Создание виртуального окружения

Для Windows:

python -m venv venv
venv\Scripts\activate

Для macOS и Linux:

python3 -m venv venv
source venv/bin/activate

2. Установка зависимостей

pip install pytest pytest-cov

Запуск тестов

Чтобы запустить все тесты проекта:

pytest

Проверка покрытия кода

Для запуска тестов с измерением покрытия класса Burger:

python -m pytest --cov=burger --cov-report=term-missing


### Что проверяют тесты

Тесты охватывают следующие методы класса Burger:

set_buns() — установка булочки.

add_ingredient() — добавление ингредиента.

remove_ingredient() — удаление ингредиента по индексу.

move_ingredient() — перемещение ингредиента.

get_price() — расчёт стоимости бургера с учётом двух булочек и ингредиентов.

get_receipt() — формирование чека с названиями булочек, ингредиентов, типами ингредиентов и итоговой стоимостью.

### Используемые подходы к тестированию

Моки (unittest.mock)

Используются для изоляции класса Burger от реализации классов Bun и Ingredient. Это позволяет контролировать возвращаемые значения методов и проверять поведение бургера независимо от других компонентов.

Параметризация (pytest.mark.parametrize)

Позволяет проверять разные сценарии удаления ингредиентов и расчёта стоимости без дублирования тестового кода.

Фикстуры (pytest.fixture)

Используются для повторного создания тестовых объектов бургера, булочки, соуса и начинки.
